## 🔍 当前副本类型说明

根据代码分析，当前有以下副本类型：

1. **SINGLE（1人本）** - 经验本，产出经验
2. **SQUAD（5人本）** - 专属道具本，产出专属材料
3. **TEAM（20人本）** - 套装材料本，产出装备材料
4. **SERVER_BOSS（世界Boss本）** - 立绘本，产出立绘碎片

每种属性（火、水、风、土、光、暗、雷、木）都有这4种类型的副本。
