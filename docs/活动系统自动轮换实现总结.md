## 🎯 功能特性

### 1. 定时任务
- **检查频率**：每30分钟
- **执行时间**：后台自动运行
- **切换精度**：最多延迟30分钟

### 2. 活动切换时机
- **团队活动**：每月1日 00:00:00（北京时间）
- **全服活动**：每季度1日 00:00:00（北京时间）
- **时区处理**：自动转换为北京时间

### 3. 前端轮询
- **轮询间隔**：每2分钟
- **自动更新**：检测到活动切换时自动更新
- **通知显示**：活动切换时显示横幅通知

### 4. 通知样式
- **位置**：页面顶部
- **样式**：渐变背景 + 动画效果
- **持续时间**：3秒（可手动关闭）

### 5. 历史记录
- **存储位置**：数据库
- **记录内容**：切换时间、活动ID、切换原因
- **查询支持**：可通过API查询历史记录

## 🔌 API接口

### 1. 获取当前活动
```
GET /api/events/active
```
返回当前活动信息和下次刷新时间

### 2. 手动触发活动切换（管理员）
```
POST /api/events/rotate
Body: {
  "event_type": "team_monthly" | "server_quarterly",
  "target_event_id": "可选，指定活动ID"
}
```

---

## 📊 数据库表

### EventRotationHistoryModel
- `history_id` - 历史记录ID
- `event_type` - 活动类型
- `old_event_id` - 旧活动ID
- `new_event_id` - 新活动ID
- `rotation_reason` - 切换原因（auto/manual）
- `rotated_at` - 切换时间
- `extra_info` - 额外信息

## 🚀 使用说明

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务器
```bash
python run_server.py
```

定时任务会自动启动，每30分钟检查一次活动是否到期。

### 3. 前端自动轮询
前端会自动每2分钟请求一次活动信息，检测到活动切换时会显示通知。

### 4. 管理员手动切换
```bash
curl -X POST http://localhost:5000/api/events/rotate \
  -H "Content-Type: application/json" \
  -d '{"event_type": "team_monthly"}'
```

---

## 📝 注意事项

1. **时区处理**：活动切换时间使用北京时间（UTC+8）
2. **进度清空**：活动切换时会清空相关任务进度
3. **定时任务**：服务器重启后定时任务会自动重新启动
4. **前端轮询**：只在活动页面进行轮询，减少服务器压力
