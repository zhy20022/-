## 📝 快速填写模板

如果您想快速定义，可以使用以下模板：

### 模板：简化版本（当前使用）

```
所有Boss：暂时不使用阶段转换和特殊机制
- Boss只是属性更高的怪物
- Boss有职业和技能槽（但技能暂时为空）
- 后续可以根据需要添加特殊机制
```

### 模板：基础版本

```
单体Boss：
- 阶段1（100%-66%）：正常属性，普通攻击
- 阶段2（66%-33%）：攻击力+20%，使用技能A
- 阶段3（33%-0%）：攻击力+50%，使用技能B

双子Boss（分离）：
- 阶段1：两个Boss都存活，互相加成
- 阶段2：一个Boss死亡后，剩余Boss变强

议会Boss（顺序）：
- Boss1 → Boss2 → Boss3，逐个激活
```
