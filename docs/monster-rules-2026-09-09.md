# 怪物技能首版接入与模拟记录

## 完成范围与边界

本轮将 9怪物 四份文本中的 64 组配置录入 Python 真实战斗运行层：16 种经验小怪、16 个五人 Boss、24 组团队 Boss、8 个全服 Boss。组合包含多个成员，因此“64 组”不是 64 个独立战斗单位。

已接入默认副本刷怪、技能施放、技能后状态结算、阶段转换、共血/独立血量、逐个激活、融合、护盾、治疗、驱散、击杀回调和战斗快照。已保存的旧管理页 Boss 自定义配置仍优先使用旧运行路径，没有被覆盖。

重要：本轮没有部署到公网。正式 Nest 在线模式尚未执行这套 Python 引擎；导出的 JSON 是后续共用配置，不代表 Nest 已支持这些战斗。原有管理页的通用九槽模板也尚未改造成这份新目录的编辑器。前端收到新技能、阶段、护盾字段，但专门的状态图标和技能预览组件尚未补齐。

## 已落实的裁定

- 风系副本生成火系怪物；水系副本生成土系怪物，其余遵循既有属性克制表。
- 经验本第一种小怪对应单体波，第二种对应群体波；既有经验本 20 波、每 3 秒一波的配置保留。
- 五人普通 Boss 按 1、2、3 顺序循环；双形态仅循环当前形态列出的技能。全服 Boss 按 1 至 9 顺序循环。
- 双形态首次低于 50% 切换；三阶段首次低于 70%、35% 切换。受击时即锁定阶段，随后回血不会退阶段；直接跨越两条阈值时进入最终阶段。
- 状态在受影响单位接下来两次成功施法后结算或到期；新施加状态不消耗当次计数。失败的条件槽位不会卡住循环，也不算成功施法。
- 周期治疗和周期伤害没有默认即时结算。每一层独立计时，叠满后不刷新旧层。
- 同来源技能护盾替换；不同来源护盾并存，受击时按剩余护盾量等比例消耗。玄冰甲胄的双防加成绑定其护盾，护盾消失即失效，多次补盾不会不断叠加绑定双防。
- 玄冥双蛟共享血池低于 30% 融合一次，清理负面状态、回复最大血量的 20%，永久双攻 +25%。融合后仅剩一个可攻击单位，循环融合前两项技能，另一成员不伪装成一次击杀。
- 明暗交界按最大生命值比例比较，差距严格超过 20 个百分点保护低血一方；差距缩小或任何一方死亡后解除。
- 四方妖兽每 30 秒按物攻、法攻、物防、法防的固定顺序轮换增益。
- 本轮配置不实现混乱、定身、反弹、致盲等附加控制；对应技能改用不暗示这些控制的名称，仅保留明确的伤害与属性变化。
- 木灵、六道召唤、雷暴分身仅记录表现事件，不新增敌人，不参与通关判定。
- 全服 Boss 的治疗只调用本场战斗血量恢复，不扣除已经记录的玩家累计有效伤害；没有写入全服共享血池的治疗路径。
- 水环缚灵仅作用于一个目标；地火喷涌降低法防；破邪之光对暗系的技能倍率为总计 3 倍，不是 4 倍。通常属性克制倍率仍单独计算。
- 闭目·永冻劫首版设为目标最大生命值 60% 的伤害，无视防御但先扣护盾，不是即死。

## 首版选择

| 组合 | 血量和行动方式 |
| --- | --- |
| 玄冥双蛟 | 共血、同时行动，30% 以下融合一次 |
| 雷吼与电芒、扶桑与若木 | 共血、同时行动 |
| 阳乌与阴蟾 | 独立血量、同时行动，阴爆/阳爆交替 |
| 负天吞火、风袋兽与风轮兽、赤焰牯与熔岩犼 | 独立血量、同时行动，死亡继承一次 |
| 影魍与石魍 | 独立血量、同时行动，差值保护 |
| 三渊洪鳌、三昧神风、四季灵木、三光星兽 | 共血、同时行动 |
| 三霄雷劫、三昧火灵、三尸邪神 | 独立血量、逐个激活，未激活者不可攻击 |
| 四方妖兽 | 独立血量、同时行动、固定轮换 |

组合共有主动技能每三个行动间隔释放一次，由一名存活成员释放，替代该成员当次普通行动，避免一项公共技能按成员数重复施放。共血池的全体治疗只恢复一次，不因显示多个头像而重复恢复。明确写“全体怪物”的治疗/护盾覆盖场上存活且已激活的怪物；双子专用增益仅作用于本组合。

保留现有刷怪时间表，每个原定 Boss 波次随机选取一组：五人从该属性的两组中选，团队从三组中选，并非将文档中的全部组合依次放出。多成员组合分摊原有单组 Boss 生命预算；没有简单地按头像数量倍增血量。

## 可调数值

- 默认行动间隔：经验小怪 6 秒，五人 Boss 4 秒，团队成员 5 秒，全服 Boss 4 秒。
- 多数普通属性变化为 15% 至 30%；高压强化为 40% 至 50%，按基础属性相加而不是连乘。减益不会将属性降成负数。
- 未明确伤害类型的技能首版采用物理/魔法各 50%，复用现有伤害计算器；明确物理的破甲雷槌、肾火灼甲按物理结算。后续可逐技能修改 `school` 字段。
- 周期伤害施加时快照伤害数值，之后按两次施法结算，不按秒触发。多段随机攻击逐段重新选取存活目标；紧随其后的单体减益跟随最后一个命中目标。
- 祸斗獒食火首版转化 50% 火系直接技能伤害；没有凭空新增反伤。
- 噬魂夺魄每个本场已死亡角色回复最大生命值 2%，同一个角色不反复提供尸体治疗。
- 玄冰甲胄护盾 12%，绑定双防 +40%；其余护盾多数 8% 至 20%，沧溟甲螈按文档保留 30%。
- 沧溟甲螈护盾技能后等待 8 秒，其余技能后等待 4 秒，降低不断补盾造成的僵局风险。
- 万木之灵每完成一次循环永久双防 +5%；天帝威能每循环永久双攻 +5%，先保留可持续叠加。正常 180 秒内约触发 5 次，即 +25%；10 次为 +50%，不是 1.05 连乘。
- 雷云压顶每次一层，霜寒锁链首版三段对应三层，每层相关防御 -5%，各自最多九层，即最高 -45%。

## 模拟结果

脚本：`scripts/simulate_authored_monsters.py`。固定种子 1701，64 组各测试 0.5、1.0、1.5 三档标准队伍，共 192 场。最新输出以 `monster-simulation-2026-09-09.json` 为准。

这是诊断场景：单组怪物、固定属性、每三个秒一次角色行动，每五人配一个简化治疗位；不是 64 个正式角色技能，也不是完整多波副本或多人网络压力测试。

当前模拟结果：180 场击败怪物、7 场队伍阵亡、5 场超时。所有失败/超时均出现在 0.5 档队伍，1.0 和 1.5 档全部可击败单组怪物。不能把这个结果解释为实际游戏通关率。

发现并调整：沧溟甲螈原先护盾补充过快，标准队伍也会超时；保留 30% 护盾并延长护盾技能后间隔后，标准队伍 93 秒通过，弱队仍可能超时。

| 受影响角色施法间隔 | 雷云压顶峰值 | 霜寒锁链峰值 |
| --- | --- | --- |
| 1 秒 | 1 层 | 3 层 |
| 3 秒 | 2 层 | 6 层 |
| 6 秒 | 3 层 | 9 层 |
| 12 秒 | 5 层 | 9 层 |

上述叠层探针固定 Boss 每 5 秒施加一次，连续观察 120 秒。达到上限不是必须触发的条件，因此“叠不到九层”没有造成技能失效；它意味着目前九层更多是极慢施法场景的保护上限。暂不改成长时异常，也不自动刷新层数。

## 仍需要验证或决定

1. 真正的角色、装备、难度数值与现有刷怪波次尚未联合模拟。本轮单组压力结果不能用于给线上怪物强弱作最终结论，尤其现有全服 Boss 工厂基础属性仍需独立定标。
2. 垂天巨鹏第二阶段、浑沌无相最终阶段等按原文只有护盾/增益，没有主动伤害；没有擅自添加新攻击。其玩法是输出门槛，可能出现队伍不掉血但打不穿的超时。后续可讨论增加基础攻击，但这将属于新技能设计。
3. 万木之灵在弱队中更容易表现为无法压低血量。当前结果不能将治疗、护盾和永久双防的影响混为一谈；正式队伍测试若仍过强，建议先减小治疗/补盾频率，而不是直接取消永久成长特色。
4. 需要把这套有版本号的配置与相同语义接入 Nest 服务端权威战斗，再做前端真实回放、断线恢复和正式结算验收。不能让前端自行计算 Boss 伤害来替代服务端。
5. 管理入口需要展示新配置的当前循环、阶段、组合、数值；旧九槽模板不能继续充当这些怪物的真实预览。

## 复现

```powershell
python -X utf8 -m pytest tests -q
.\.venv\Scripts\python.exe -X utf8 scripts/simulate_authored_monsters.py
```

模拟脚本会重新生成诊断 JSON 和 `data/content/monster-catalog.json`。它不读取玩家存档、不连接数据库，也不会部署到线上。
