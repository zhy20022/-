## 📝 使用方式

### 1. 基本使用
切换按钮会自动显示在右上角（已登录时），点击即可切换横竖屏。

### 2. 在组件中使用方向检测
```typescript
import { useOrientation } from '../hooks/useOrientation'

function MyComponent() {
  const { isPortrait, isMobile } = useOrientation()
  
  return (
    <div className={isPortrait ? 'portrait' : 'landscape'}>
      {/* 内容 */}
    </div>
  )
}
```

### 3. 自定义切换按钮
```typescript
import OrientationToggle from '../components/OrientationToggle'

<OrientationToggle 
  position="top-left" 
  showLabel={false} 
/>
```
