    - 2->3级：160个专属道具材料
    - 3->4级：320个专属道具材料
  - 每级提升10%属性

- **套装升级：**
  - 分为5个等级（0-4级，最高5级）
  - 升级消耗（每一级需要的材料增加）：

    - 1->2级：4份套装材料
    - 2->3级：8份套装材料
    - 3->4级：16份套装材料
  - 每级提升10%属性
  - 套装加成（2件、4件、6件）也会随等级提升

## 🎯 使用示例

### 1. 材料系统

```python
from src.rewards.material import MaterialBag, Material, MaterialType
from src.attributes.attribute import AttributeType

# 创建材料背包
bag = MaterialBag("player_001")

# 添加材料
exclusive_material = Material(
    material_id="exclusive_material_001",
    material_type=MaterialType.EXCLUSIVE_ITEM,
    name="专属道具材料"
)
bag.add_material(exclusive_material, 100)

# 筛选材料
fire_materials = bag.filter_materials(
    material_type=MaterialType.EQUIPMENT_SET,
    attribute_type=AttributeType.FIRE
)
```
