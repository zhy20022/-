# 横竖屏切换功能说明

## 📱 功能概述

参考 **NEOWIZ 棕色尘埃2** 的横竖屏切换体验，实现了流畅的屏幕方向切换功能，支持：
- ✅ 手机竖屏和横屏模式
- ✅ Steam 桌面端适配
- ✅ 流畅的切换动画
- ✅ 自动方向检测
- ✅ 方向偏好记忆

---

## 🎯 核心功能

### 1. 屏幕方向检测
- 自动检测当前屏幕方向（竖屏/横屏）
- 支持 Screen Orientation API（现代浏览器）
- 降级方案：使用窗口尺寸判断
- 实时监听方向变化

### 2. 方向切换按钮
- 位置：右上角（可配置）
- 显示：仅在已登录时显示
- 功能：一键切换横竖屏
- 动画：流畅的切换过渡效果

### 3. 方向锁定（移动端）
- 在移动设备上可以锁定屏幕方向
- 支持 portrait（竖屏）和 landscape（横屏）锁定
- auto 模式：允许自动旋转

### 4. 偏好记忆
- 自动保存用户的方向偏好到 localStorage
- 下次打开时自动恢复偏好设置

### 核心 Hook: `useOrientation`

```typescript
const {
  orientation,      // 当前方向偏好: 'portrait' | 'landscape' | 'auto'
  isPortrait,      // 是否为竖屏
  isLandscape,     // 是否为横屏
  screenWidth,     // 屏幕宽度
  screenHeight,    // 屏幕高度
  isMobile,        // 是否为移动设备
  isDesktop,       // 是否为桌面设备
  setOrientation,  // 设置方向偏好
  toggleOrientation // 切换方向
} = useOrientation()
```

### 使用示例

#### 在组件中使用方向检测
```typescript
import { useOrientation } from '../hooks/useOrientation'

function MyComponent() {
  const { isPortrait, isMobile } = useOrientation()
  
  return (
    <div className={isPortrait ? 'portrait-layout' : 'landscape-layout'}>
      {isMobile ? '移动端' : '桌面端'}
    </div>
  )
}
```

#### 添加切换按钮
```typescript
import OrientationToggle from '../components/OrientationToggle'

function MyPage() {
  return (
    <div>
      <OrientationToggle position="top-right" showLabel={true} />
      {/* 页面内容 */}
    </div>
  )
}
```

## 📐 响应式布局

### CSS 类名
应用容器会自动添加以下类名：
- `.app-orientation-container` - 方向容器
- `.portrait` - 竖屏模式
- `.landscape` - 横屏模式
- `.mobile` - 移动设备
- `.desktop` - 桌面设备
- `.orientation-transitioning` - 切换过渡中

### 样式示例
```css
/* 竖屏布局 */
.app-orientation-container.portrait .my-component {
  flex-direction: column;
}

/* 横屏布局 */
.app-orientation-container.landscape .my-component {
  flex-direction: row;
}

/* 移动端竖屏 */
.app-orientation-container.mobile.portrait .my-component {
  /* 移动端竖屏特定样式 */
}

/* 桌面端横屏（Steam） */
.app-orientation-container.desktop.landscape .my-component {
  /* 桌面端横屏特定样式 */
}
```

## 🎮 Steam 适配

### 桌面端行为
- 在桌面端（Steam），方向切换主要用于预览不同布局
- 不会强制锁定屏幕方向（桌面端通常不支持）
- 支持窗口模式和全屏模式

### 窗口尺寸适配
- 自动检测窗口尺寸变化
- 根据窗口宽高比判断方向
- 支持窗口拖拽调整大小

---

## 📱 移动端特性

### iOS 支持
- 支持 Screen Orientation API
- 支持方向锁定
- 支持 Safari 浏览器

### Android 支持
- 支持 Screen Orientation API
- 支持方向锁定
- 支持 Chrome、Firefox 等浏览器

### 触觉反馈
- 在支持的设备上，切换方向时会有轻微震动反馈

## 🎨 动画效果

### 切换动画
- 持续时间：400ms
- 缓动函数：`cubic-bezier(0.4, 0, 0.2, 1)`
- 效果：淡入淡出 + 轻微缩放

### 按钮动画
- 悬停效果：轻微上移 + 阴影增强
- 点击效果：轻微下压
- 图标旋转：90度旋转动画

## ⚙️ 配置选项

### OrientationToggle 组件属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `className` | `string` | `''` | 自定义类名 |
| `showLabel` | `boolean` | `true` | 是否显示文字标签 |
| `position` | `string` | `'top-right'` | 按钮位置 |

### 位置选项
- `top-right` - 右上角
- `top-left` - 左上角
- `bottom-right` - 右下角
- `bottom-left` - 左下角
- `center` - 居中

## 📝 使用建议

### 1. 页面布局优化
建议为不同方向设计不同的布局：
- **竖屏**：适合列表、详情页、聊天界面
- **横屏**：适合战斗、地图、多列内容

### 2. 按钮位置
- 默认位置：右上角（不遮挡主要内容）
- 可根据页面需求调整位置

### 3. 方向偏好
- 用户的选择会自动保存
- 下次打开时自动恢复

## 🐛 已知问题

### 1. 某些浏览器不支持方向锁定
- **问题**：部分浏览器（如某些移动浏览器）不支持 `screen.orientation.lock()`
- **解决**：自动降级，不影响基本功能

### 2. 桌面端方向切换
- **问题**：桌面端无法真正锁定屏幕方向
- **解决**：主要用于预览不同布局，不影响使用
