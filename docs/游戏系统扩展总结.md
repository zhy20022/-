# 游戏系统扩展总结

基于**天命之子**、**弹射世界**、**失落的龙约**等游戏的设计模式，已实现以下系统扩展：

## ✅ 已实现的新系统

### 1. 装备强化系统（参考天命之子）

**文件位置**: `src/rewards/equipment_enhancement.py`

**核心功能**:
- **强化系统**: 装备可强化至50级，每级提升2%属性
- **突破系统**: 每10级需要突破（10/20/30/40/50），突破后属性大幅提升20%
- **成功率机制**: 随等级降低（0-9级100%，10-19级80%，20-29级60%，30-39级40%，40-49级20%，50级10%）
- **失败惩罚**: 强化失败会掉级（可使用保护符避免）
- **消耗系统**: 需要金币和装备材料，消耗随等级递增

**使用示例**:
```python
from src.rewards.equipment_enhancement import EquipmentEnhancementSystem
from src.rewards.material import MaterialBag

material_bag = MaterialBag("player_001")
enhancement_system = EquipmentEnhancementSystem("player_001", material_bag, gold=100000)

# 强化装备
result = enhancement_system.enhance_equipment(equipment, current_enhancement_level=5)
if result.success:
    print(f"强化成功！新等级：{result.new_enhancement_level}")

# 突破装备
if equipment_enhancement_level == 10:
    result = enhancement_system.breakthrough_equipment(equipment, 10)
```

### 2. 任务系统（参考失落的龙约）

**文件位置**: `src/game/quest_system.py`

**核心功能**:
- **任务类型**: 主线任务、支线任务、日常任务、周常任务、成就任务
- **任务目标**: 支持多种目标类型（击杀怪物、完成副本、强化装备等）
- **解锁机制**: 支持条件解锁
- **自动重置**: 日常任务每日重置，周常任务每周重置
- **进度追踪**: 自动追踪任务进度

**使用示例**:
```python
from src.game.quest_system import QuestSystem

quest_system = QuestSystem("player_001")

# 接取任务
quest_system.accept_quest("daily_001")

# 更新任务进度（完成副本时调用）
quest_system.update_quest_progress("complete_dungeon", count=1)

# 领取奖励
reward = quest_system.claim_quest_reward("daily_001")
```

### 3. 成就系统（参考弹射世界）

**文件位置**: `src/game/achievement_system.py`

**核心功能**:
- **成就分类**: 战斗、副本、角色、装备、社交、收集、里程碑
- **稀有度系统**: 普通、稀有、史诗、传说
- **隐藏成就**: 支持隐藏成就（未解锁前不显示）
- **自动解锁**: 根据玩家数据自动检查并解锁成就
- **进度统计**: 按分类和稀有度统计成就进度

**使用示例**:
```python
from src.game.achievement_system import AchievementSystem

achievement_system = AchievementSystem("player_001")

# 检查成就（在玩家数据更新时调用）
player_data = {
    "battles_completed": 100,
    "character_count": 10
}
newly_unlocked = achievement_system.check_achievements(player_data)

# 获取成就进度
progress = achievement_system.get_achievement_progress(player_data)
```

### 4. 签到系统（参考天命之子）

**文件位置**: `src/game/daily_checkin.py`

**核心功能**:
- **每日签到**: 每日可签到一次
- **连续签到**: 追踪连续签到天数
- **周奖励**: 7天循环奖励，第7天特殊奖励
- **月奖励**: 30天循环奖励，第30天特殊奖励
- **奖励预览**: 可查看下次签到奖励

**使用示例**:
```python
from src.game.daily_checkin import DailyCheckIn

checkin_system = DailyCheckIn("player_001")

# 执行签到
result = checkin_system.check_in()
if result["success"]:
    print(f"签到成功！连续签到{result['consecutive_days']}天")
    print(f"获得奖励：{result['reward']}")

# 获取签到状态
status = checkin_system.get_checkin_status()
print(f"今日是否可签到：{status['can_check_in']}")
```

### 5. 好友与助战系统（参考失落的龙约）

**文件位置**: `src/social/friend_system.py`

**核心功能**:
- **无限好友**：玩家可添加任意数量好友，无上限。
- **助战切换**：全局助战开关，启用后副本掉落转换为 `1000` 通用助战币。
- **API 支持**：`/api/social/friends` 列表/新增/删除好友，`/api/social/assist-mode` 切换助战模式。
- **Battle 集成**：`BattlePage` 新增助战开关，助战掉落以货币形式展示。

### 6. 活动轮换系统（参考天命之子）

**文件位置**: `src/events/event_system.py`

- **20人团队月度轮换**：按属性（火、水、雷等）顺序自动巡回。
- **全服季度轮换**：每季度对应季节活动，聚焦特定属性。
- **API**：`/api/events/active` 返回当前活动及下次刷新时间。

### 7. 活动商店（参考天命之子）

**文件位置**: `src/events/event_system.py`（库存） + `web/src/pages/ShopPage.tsx`

- **UI 规则**：右上角显示材料数，每行 4 个商品，按属性分区。
- **商品全可兑换**：无折扣、无刷新限制，所需材料均可通过正常玩法获取。
- **API**：`/api/shop/items` 返回按属性分组的商品与当前材料。前端 `ShopPage` + `ShopPage.css` 提供展示与交互。

## 📊 系统集成建议

### 1. 与战斗系统集成

在战斗结束时，更新任务和成就进度：

```python
# 在战斗结束后
quest_system.update_quest_progress("complete_dungeon", dungeon_id, count=1)
quest_system.update_quest_progress("kill_monster", monster_id, count=monsters_killed)

player_data = {
    "battles_completed": player.total_battles,
    "dungeons_completed": player.total_dungeons
}
achievement_system.check_achievements(player_data)
```

### 2. 与装备系统集成

在装备强化时，更新任务进度：

```python
# 装备强化后
quest_system.update_quest_progress("upgrade_equipment", count=1)

player_data = {
    "max_equipment_enhancement": player.max_equipment_level
}
achievement_system.check_achievements(player_data)
```

### 3. 每日重置

在服务器启动或每日0点时重置：

```python
# 每日重置
quest_system.reset_daily_quests()
checkin_system.get_checkin_status()  # 自动检查是否需要重置
```
