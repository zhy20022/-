## 🔌 新增/更新的API接口

### 1. 获取副本列表（更新）
```
GET /api/dungeons
```
**新增返回字段：**
- `progress`: 副本进度信息
  - `completion_count`: 完成次数
  - `total_attempts`: 总挑战次数
  - `sweep_unlocked`: 扫荡是否解锁
  - `best_record`: 最佳记录

### 2. 获取副本详情（新增）
```
GET /api/dungeons/<dungeon_id>
```
**返回：**
```json
{
  "success": true,
  "dungeon": {
    "dungeon_id": "...",
    "name": "...",
    "progress": {...},
    "reward_config": {...}
  }
}
```

### 3. 扫荡副本（新增）
```
POST /api/dungeons/<dungeon_id>/sweep
```
**请求体：**
```json
{
  "count": 1  // 扫荡次数（1-10）
}
```

**返回：**
```json
{
  "success": true,
  "message": "扫荡成功，获得奖励",
  "sweep_count": 1
}
```

## 📊 数据结构

### Dungeon接口（前端）
```typescript
interface Dungeon {
  dungeon_id: string
  name: string
  dungeon_type: string  // SINGLE, SQUAD, TEAM, SERVER_BOSS
  attribute_type: string
  is_unlocked: boolean
  description?: string
  duration?: number
  reward_config?: {
    type: string  // experience, exclusive_material, equipment_material, illustration_piece
    base_exp?: number
    base_material?: number
    // ...
  }
  progress?: {
    completion_count: number
    total_attempts: number
    sweep_unlocked: boolean
    best_record: {
      duration?: number
      rewards?: any
    }
  }
}
```

## 🎯 功能说明

### 标签页切换
- 点击标签页立即切换显示的副本类型
- "全部"标签页显示所有副本
- 其他标签页只显示对应类型的副本

### 扫荡功能
- **解锁条件**：通关50次后解锁
- **支持类型**：只有1人本和5人本支持扫荡
- **扫荡次数**：支持1-10次
- **扫荡限制**：20人本和世界Boss本不支持扫荡

### 副本进度
- **完成次数**：统计成功完成的次数
- **总挑战次数**：统计所有挑战次数（包括失败）
- **最佳记录**：记录最佳完成时间和奖励
- **扫荡解锁**：通关50次后自动解锁

### 掉落物品显示
- **经验本**：显示经验值
- **材料本**：显示专属材料数量
- **装备本**：显示装备材料数量
- **立绘本**：显示立绘碎片（随机）
