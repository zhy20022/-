## 📝 当前实现

### 怪物生成

```python
# 1人本怪物
- 等级：10级
- 属性：根据副本属性克制关系（火副本的怪物是木属性）
- 属性值：基础属性 × 时间倍率
- 职业：无
- 技能：无（只普通攻击）

# 5人本怪物
- 等级：20级
- 属性：根据副本属性克制关系
- 属性值：基础属性 × 时间倍率
- 职业：无
- 技能：无（只普通攻击）

# 20人本怪物
- 等级：30级
- 属性：根据副本属性克制关系
- 属性值：基础属性 × 时间倍率
- 职业：无
- 技能：无（只普通攻击）

# Boss
- 等级：根据副本类型（10/20/30级）
- 属性：根据副本属性克制关系
- 属性值：小怪的5倍 × 时间倍率
- 职业：有（随机选择，暂时）
- 技能：有技能槽（但暂时为空，后续可以添加特殊技能）
```

### 全服Boss系统

```python
# 伤害统计
- 方式：累计统计（每个玩家单独挑战）
- 记录：每个玩家的本周最高一次伤害
- 排名：显示前100名

# 每周结算
- 方式：固定时间结算
- 次数：14次
- 间隔：每12小时一次
- 奖励：立绘拼图碎片，所有人相同奖励

# Boss血量
- 方式：无限血量（只统计伤害，不击杀Boss）
```
