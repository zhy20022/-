## 🔌 新增API接口

### 1. 锁定角色
```
POST /api/characters/<character_id>/lock
```

**返回：**
```json
{
  "success": true,
  "message": "角色已锁定"
}
```

### 2. 解锁角色
```
POST /api/characters/<character_id>/unlock
```

**返回：**

```json
  "success": true,
  "message": "角色已解锁"
}
```

## 📊 数据结构

### Character接口（前端）
```typescript
interface Character {
  character_id: string
  name: string
  profession_type: string
  attribute_type: string
  level: number
  exp: number
  star?: number  // 星级（1-5）
  is_locked?: boolean  // 是否锁定
  stats?: {...}
  equipment?: {...}
  skills?: {...}
}
```

### 锁定状态存储
- 锁定状态存储在 `equipment` JSON字段中的 `is_locked` 键
- 星级存储在 `equipment` JSON字段中的 `star` 键

## 🎯 功能说明

### 职业分类识别
系统会自动从职业名称中识别职业分类：
- 包含"坦克" → TANK
- 包含"输出" → DPS
- 包含"治疗"或"辅助" → HEALER/SUPPORT

### 职业类型识别
系统会自动从职业名称中识别职业类型：
- 包含"物理" → PHYSICAL
- 包含"法系"或"魔法" → MAGIC

### 星级计算
如果没有设置星级，系统会根据等级自动计算：
- 星级 = min(5, floor(等级 / 20) + 1)
