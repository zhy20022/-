## 📝 填写示例

### 示例1：简单副本（推荐）
```
1. 副本结构：单场战斗
2. 副本难度：不需要难度系统
3. 副本怪物：
   - 单人：1-3个怪物
   - 五人：5-10个怪物 + 1个Boss
   - 二十人：20-30个怪物 + 3个Boss
4. 副本奖励：
   - 单人：经验值 + 基础材料×10
   - 五人：专属武器材料×50 + 副本内装备（攻击+100）
   - 二十人：套装材料×100 + 副本内饰品（防御+50）
5. 副本内装备：固定装备，攻击+100，防御+50
6. 副本进度：不保存进度，无限次数
7. 副本解锁：
   - 单人：无
   - 五人：满级100级
   - 二十人：拥有五人小队
8. Boss系统：无特殊机制
```

### 示例2：复杂副本
```
1. 副本结构：多场战斗（3场）
2. 副本难度：普通/困难/噩梦（100%/150%/200%）
3. 副本怪物：分波次出现，每波3-5个
4. 副本奖励：每场战斗有奖励，最终Boss有额外奖励
5. 副本内装备：随机掉落，可替换
6. 副本进度：保存进度，有检查点
7. 副本解锁：需要完成前置副本
8. Boss系统：阶段转换 + 特殊技能
```
