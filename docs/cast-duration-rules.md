# 技能效果持续次数

「持续到后两个技能释放完结束」指效果施加后生效，持续至施加者接下来第 2 个技能结算完毕。角色与怪物共用此规则，不论目标是自己、队友还是敌方单位。

- 施加当次不扣次数；只计施加者后续成功结算的技能。多段攻击和多个目标不会把同一技能计为多次；其他单位施法不扣次数。怪物死亡触发、阶段机制等不进入常规施法计数的效果仍不计入。
- 第 2 个技能的所有命中、治疗和按施法触发的效果均可享受该状态，结算后才移除。持续伤害、持续治疗也在施加者的后续技能结算时触发，最后一跳不会因到期丢失。
- 多个施加者各自计数。四次、七次等明确写明的次数按同一规则；按秒、本场战斗永久、提前驱散、消耗或破盾仍按原条件执行。

闻微按 A → B → C 连招且命中同一目标时，A 结算伤害后施加「气滞」，B 结算后剩一次，C 结算时仍可享受 15% 法防降低并触发对应的 60% 追加伤害，随后「气滞」到期。敌人即使在中间施法多次，也不影响这个连招窗口。

旧版按效果持有者施法计数所得的伤害数据和排名，不适用于本规则。应用新计时、尚未调平时，32 名输出角色的裸装单敌 ABC 十轮首尾为 46,990 / 17,450，约 2.69 倍。逐一削弱 5 名越线角色后，在相同口径下首尾为 34,298 / 17,450，约 1.966 倍。闻微仍为 33,160，气滞计时与技能倍率不变。
