## 📝 快速填写模板

如果您想快速开始，可以使用以下简化模板：

### 模板1：简单副本（推荐）
```
副本结构：单场战斗
难度系统：普通难度（100%属性，100%奖励）
怪物配置：
- 单人：1-3个怪物
- 五人：5-10个怪物 + 1个Boss
- 二十人：20-30个怪物 + 3个Boss
奖励系统：
- 单人：经验值 + 基础材料
- 五人：专属武器材料 + 副本内装备
- 二十人：套装材料 + 副本内饰品
副本内装备：固定装备，属性加成，无法带出
进度管理：不保存进度，退出即重置
解锁条件：
- 单人：无
- 五人：满级
- 二十人：拥有五人小队
Boss系统：无特殊机制
```

### 模板2：复杂副本
```
副本结构：多场战斗（3-5场）
难度系统：普通/困难/噩梦（100%/150%/200%）
怪物配置：分波次出现
奖励系统：每场战斗有奖励，最终Boss有额外奖励
副本内装备：随机掉落，可替换
进度管理：保存进度，有检查点
解锁条件：需要完成前置副本
Boss系统：阶段转换 + 特殊技能
```
