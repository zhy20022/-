## 📝 快速填写模板

如果您想快速开始，可以使用以下简化模板：

### 模板1：简单版本（推荐）

```
1. 怪物生成逻辑：
   - 怪物属性：根据玩家等级计算（玩家等级 × 倍数）
   - 怪物等级：根据玩家等级（怪物等级 = 玩家等级）
   - 怪物职业：没有职业
   - 怪物技能：没有技能（只普通攻击）
   - 群体小怪：相同属性

2. Boss特殊机制：
   - 单体Boss：不需要阶段转换
   - 双子Boss：不需要特殊机制
   - 议会Boss：不需要特殊机制

3. 全服Boss系统：
   - 伤害统计：累计统计（每个玩家单独挑战）
   - 每周结算：固定时间（每周一0:00）
   - Boss血量：固定血量（1,000,000,000 HP）
   - Boss技能：暂时不考虑
   - 伤害排名：不需要排名（所有人相同奖励）
```

### 模板2：完整版本

```
1. 怪物生成逻辑：
   - 怪物属性：根据副本难度计算（基础属性 × 难度倍率 × 时间倍率）

2. Boss特殊机制：
   - 单体Boss：3个阶段（100%-66%-33%-0%）
   - 双子Boss：共血量，2个阶段
   - 议会Boss：顺序激活，3个Boss

3. 全服Boss系统：
   - 伤害统计：实时统计（所有玩家同时攻击）
   - 每周结算：动态时间（Boss死亡后结算）
   - Boss血量：根据玩家数量计算
   - Boss技能：需要特殊技能（全屏攻击、召唤小怪）
```
