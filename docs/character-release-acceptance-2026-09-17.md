# 64角色发布前验收

## 范围

正式技能清单包含64角色、192项A/B/C技能，无待裁定角色。覆盖本轮已确认的技能机制、可重复配置的9槽、底/中/高梯度随机施法和真实服务器结算。

## 已通过

- Python全量：212项测试、438个子场景；仅5项已有弃用警告。
- 64角色真实NestJS/PostgreSQL HTTP联调：320种布局保存并核对SQL、跨账号拒绝、非法配置拒绝、每名角色实际A/B/C事件、战斗快照及重复结算同一记录。
- HTTP联调只在隔离本地数据库推进结算时钟，不修改引擎胜负、伤害、经验、金币和奖励。
- 24个Boss副本使用真实角色队伍：1280/390两种宽度共48次展示检查，24次浏览器结算与PostgreSQL的胜负、时长和伤害一致。
- 9槽编辑界面在1280/390宽度保存、重复技能配置和刷新恢复通过。
- 四类Node/Python战斗进程联调、技能槽规则与服务测试、NestJS构建与lint、前端生产构建和TypeScript检查通过。
- 在线API覆盖检查通过15条路由；5条未接管入口仍保留保护，不据此声明全游戏在线功能完成。

## 最新规则

- 淳于绝：阴阳息总计0或1层为100%风属性物理单体伤害；保留两阳300%群体、两阴250%群体减防、一阴一阳420%单体，仍应用已积蓄增伤和暴击。
- 默渊：纳渊有效期间后续施法释放剩余水压35%；结束时一次性清算全部余量；技能3可先清空；允许护盾承担；超上限正常承伤；真实伤害不暂存。
- 法术伤害使用法攻；真实伤害不参与暂存或类型转换；云无羁转伤保留物理来源份额。

## 边界与后续

这些测试证明所覆盖流程和断言通过，不等于穷举所有64角色组合、所有随机种子和数值平衡。Boss验收使用固定的真实角色队伍，并非全部阵容的强度测试。

发布完成还需核对Render运行版本、GitHub Pages状态及Sites部署状态，并执行公网新账号流程；不得仅以构建成功代替公网验收。
