## 🚀 使用示例

### 1. 获取副本

```python

# 输出：火系经验本-火属性1人本（fire_type_single_001）
```

### 2. 检查解锁条件

```python

    "is_solo": True,

        {"level": 100, "attribute": "火", "profession": "物理坦克"},

    ],
```

### 3. 创建副本战斗

```python
from src.dungeons.dungeon_battle import DungeonBattle

# 创建副本战斗
dungeon_battle = DungeonBattle.create_dungeon_battle(
    dungeon=dungeon,
    player_characters=[character1, character2, ...],
    is_multiplayer=False

# 准备角色

# 开始战斗

# 更新战斗

```

## 📋 副本配置详情

### 1人本（经验本）
- **时长**：1分钟
- **怪物**：20波小怪（每3秒一波）
- **奖励**：
  - 坚持1分钟：10点经验
  - 坚持30秒：5点经验
  - 每杀一个小怪：0.1经验
  - 每杀5个群体小怪：0.1经验
- **扫荡**：通关50次后解锁

### 5人本（专属道具本）
- **时长**：2分钟
- **怪物**：60波小怪（每1秒一波）+ 4个Boss（2:00, 2:15, 2:30, 2:45）
- **奖励**：
  - 坚持30秒：2个材料（10%×20）
  - 坚持60秒：4个材料（20%×20）
  - 坚持90秒：10个材料（50%×20）
  - 坚持120秒：20个材料（100%×20）
  - 击杀Boss：5个材料（25%×20）
- **扫荡**：单人通关50次后解锁
- **4倍速**：多人组队共同同意后发起
- **局内道具**：随机掉落，影响当前副本战斗

### 20人本（装备本）
- **时长**：3分钟
- **怪物**：60波小怪（每1秒一波）+ 6个Boss（2:00, 2:15, 2:30, 2:45, 3:15×2）
- **奖励**：
  - 坚持3分钟：1个装备材料
  - 击杀Boss：5%概率获得1个装备材料
- **扫荡**：不能扫荡
- **4倍速**：4名玩家共同同意后发起
- **局内饰品**：随机掉落，影响当前副本战斗

### 世界boss本（立绘本）
- **时长**：3分钟
- **怪物**：1个Boss
- **奖励**：全服结算，所有人获得相同奖励
- **结算**：每周14次结算机会，按照每周最高一次伤害进行结算
- **扫荡**：不能扫荡
- **4倍速**：不能使用

## 📝 注意事项

1. **属性克制**：副本里的怪物属性一定是被该属性的角色克制的
   - 例如：火副本的怪物是木属性（火克木）

2. **扫荡模式**：1人本和5人本通关50次后解锁扫荡

3. **4倍速**：多人模式下，所有玩家同意后可以使用4倍速

4. **副本内装备**：5人本和20人本会掉落局内道具/饰品，无法带出副本

5. **奖励计算**：根据坚持时间和击杀数量计算奖励
