## 核心特性

### 1. 职业系统
- **8种职业**：物理坦克、物理近战输出、物理远程输出、法系坦克、法系近战输出、法系远程输出、治疗、辅助
- **职业属性**：每个职业有独特的基础属性配置
- **职业判断**：提供方法判断职业类型（物理/法系、坦克/输出等）

### 2. 属性相克系统
- **相克关系**：
  - 风 → 火 → 木 → 风（循环）
  - 雷 → 水 → 土 → 雷（循环）
  - 光 ⇄ 暗（相互克制）
- **伤害计算**：克制150%，被克制75%，正常100%

### 3. 游戏模式
- **单人模式**：每日重置，用于升级
- **五人小队**：每周重置，获取专属武器材料
- **二十人团队**：每月重置，获取套装材料
- **全服活动**：每季度重置，获取立绘材料

### 4. 立绘系统
- **无性别设计**：角色没有固定性别
- **玩家自定义**：玩家自行选择立绘性别
- **联机显示**：每个玩家看到自己选择的立绘

### 5. 版本隔离
- **版本绑定**：角色绑定到特定版本
- **版本隔离**：旧版本角色无法参与新版本内容
- **防止膨胀**：避免跨版本数值问题
