# 游戏启动指南

## 📋 前置要求

在启动游戏之前，请确保已安装以下软件：

### 1. Python 3.8+
- 下载地址：https://www.python.org/downloads/
- 安装后验证：打开命令行，输入 `python --version` 或 `python3 --version`

### 2. Node.js 16+
- 下载地址：https://nodejs.org/
- 安装后验证：打开命令行，输入 `node --version` 和 `npm --version`

### 3. PostgreSQL 12+
- 下载地址：https://www.postgresql.org/download/
- 安装后需要：
  - 创建数据库（默认名称：`gamedb`）
  - 记住数据库用户名和密码（默认：`postgres` / `postgres`）

---

## 🚀 快速启动步骤

### 第一步：安装 Python 依赖

在项目根目录（`Gamer` 文件夹）打开命令行，执行：

```bash
pip install -r requirements.txt
```

**注意**：如果使用 Python 3，可能需要使用 `pip3`：
```bash
pip3 install -r requirements.txt
```

### 第二步：安装前端依赖

进入 `web` 目录，安装 Node.js 依赖：

```bash
cd web
npm install
```

**Windows PowerShell 用户**：
```powershell
cd web; if ($?) { npm install }
```

### 第三步：配置数据库（可选）

游戏默认使用以下数据库配置：
- 数据库名：`gamedb`
- 用户名：`postgres`
- 密码：`postgres`
- 主机：`localhost`
- 端口：`5432`

**如果需要修改配置**，可以创建 `.env` 文件（在项目根目录）：

```env
DATABASE_URL=postgresql://用户名:密码@主机:端口/数据库名
```

例如：
```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/gamedb
```

**首次运行会自动创建所有数据表**，无需手动创建。

### 第四步：启动后端服务器

在项目根目录打开**第一个命令行窗口**，执行：

```bash
python run_server.py
```

**Windows PowerShell 用户**：
```powershell
python run_server.py
```

**如果使用 Python 3**：
```bash
python3 run_server.py
```

看到以下输出表示启动成功：
```
启动服务器: http://0.0.0.0:5000
调试模式: False
定时任务调度器已启动（活动轮换检查：每30分钟）
 * Running on http://127.0.0.1:5000
```

**保持这个窗口打开**，不要关闭。

### 第五步：启动前端开发服务器

在项目根目录打开**第二个命令行窗口**，执行：

```bash
cd web
npm run dev
```

**Windows PowerShell 用户**：
```powershell
cd web; if ($?) { npm run dev }
```

看到以下输出表示启动成功：
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

**保持这个窗口打开**，不要关闭。

### 第六步：访问游戏

打开浏览器，访问：
- **前端地址**：http://localhost:5173/
- **后端 API**：http://localhost:5000/api/

---

## 🎮 开始游戏

1. 打开浏览器访问 http://localhost:5173/
2. 首次访问需要**注册账号**（输入用户名和密码）
3. 登录后即可开始游戏

## ⚠️ 常见问题

### 问题1：`pip` 命令不存在
**解决方案**：
- Windows：使用 `python -m pip` 或 `py -m pip`
- Linux/Mac：使用 `pip3` 或 `python3 -m pip`

### 问题2：`npm` 命令不存在
**解决方案**：
- 确认已安装 Node.js
- 重新安装 Node.js：https://nodejs.org/

### 问题3：数据库连接失败
**错误信息**：`psycopg2.OperationalError` 或 `无法连接到数据库`

**解决方案**：
1. 确认 PostgreSQL 服务已启动
   - Windows：在服务管理器中启动 PostgreSQL 服务
   - Linux：`sudo systemctl start postgresql`
   - Mac：`brew services start postgresql`
2. 确认数据库已创建：
   ```sql
   CREATE DATABASE gamedb;
   ```
3. 检查 `.env` 文件中的 `DATABASE_URL` 配置是否正确

### 问题4：端口被占用
**错误信息**：`Address already in use` 或 `端口已被占用`

**解决方案**：
- 后端端口（5000）：修改 `run_server.py` 或设置环境变量 `PORT=其他端口`
- 前端端口（5173）：修改 `web/vite.config.ts` 中的端口配置

### 问题5：前端无法连接后端
**解决方案**：
1. 确认后端服务器已启动（http://localhost:5000）
2. 检查浏览器控制台（F12）是否有 CORS 错误
3. 确认 `src/server/app.py` 中的 CORS 配置允许前端地址

### 问题6：模块导入错误
**错误信息**：`ModuleNotFoundError` 或 `ImportError`

**解决方案**：
1. 确认在项目根目录执行命令
2. 确认已安装所有依赖：`pip install -r requirements.txt`
3. 如果使用虚拟环境，确认已激活虚拟环境

## 🔧 开发模式说明

### 后端开发模式
- 默认端口：`5000`
- 调试模式：可通过环境变量 `DEBUG=True` 启用
- 热重载：修改代码后需要手动重启服务器

### 前端开发模式
- 默认端口：`5173`（Vite 自动分配）
- 热重载：修改代码后自动刷新浏览器
- 支持 TypeScript 和 React 热更新

## 📦 生产环境部署

### 构建前端
```bash
cd web
npm run build
```

构建产物在 `web/dist` 目录。

### 配置生产环境
1. 设置环境变量：
   ```env
   DEBUG=False
   SECRET_KEY=你的密钥（随机生成）
   DATABASE_URL=生产数据库地址
   ```
2. 使用生产级 WSGI 服务器（如 Gunicorn）运行后端
3. 使用 Nginx 等反向代理服务器
