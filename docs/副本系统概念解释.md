# 副本系统概念解释

## 📖 什么是"副本定义系统"？

"副本定义系统"就是**创建一个副本需要定义哪些信息**。就像你要做一道菜，需要知道：
- 菜名是什么（副本名称）
- 需要什么材料（怪物配置）
- 怎么做（战斗流程）
- 什么时候可以做（解锁条件）

---

## 1. 副本类（Dungeon Class）

### 📝 这是什么意思？

**副本类**就是副本的基本信息，就像一个人的身份证：
- 名字
- ID（唯一标识）
- 类型（单人/五人/二十人）
- 描述（这个副本是干什么的）

### 🎯 具体选项

#### A. 副本名称
你想给副本起什么名字？

**选项：**
- [ ] 使用简单名称（如：火焰洞窟、冰霜森林、雷电神殿）
- [ ] 使用编号名称（如：副本1、副本2、副本3）
- [ ] 使用描述性名称（如：新手训练场、高级试炼场）
- [ ] **您的选择：** _______________

**示例：**
- "火焰洞窟" - 单人野外副本
- "深渊试炼" - 五人小队副本
- "异度空间核心" - 二十人团队副本

#### B. 副本ID
每个副本需要一个唯一标识（就像身份证号）

**选项：**
- [ ] 使用数字ID（如：dungeon_001、dungeon_002）
- [ ] 使用名称ID（如：fire_cave、ice_forest）
- [ ] **您的选择：** _______________

**示例：**
- `dungeon_solo_001` - 单人副本1
- `dungeon_team_001` - 五人小队副本1
- `dungeon_raid_001` - 二十人团队副本1

#### C. 副本描述
副本的介绍文字（告诉玩家这个副本是干什么的）

**选项：**
- [ ] 简单描述（如：一个充满火焰的洞窟）
- [ ] 详细描述（如：这是一个充满火焰的洞窟，里面居住着强大的火元素生物...）
- [ ] 不需要描述
- [ ] **您的选择：** _______________

**示例：**
- "一个充满火焰的洞窟，小心被烧伤！"
- "异度空间的核心区域，需要强大的团队才能挑战"

---

## 2. 数据配置（Data Configuration）

### 📝 这是什么意思？

**数据配置**就是副本里具体有什么内容：
- 里面有多少怪物
- 怪物是什么等级
- 有什么奖励
- 副本多长时间

### 🎯 具体选项

#### A. 副本时长
副本最多可以打多长时间？

**选项：**
- [ ] 单人野外：1分钟
- [ ] 五人小队：2分钟
- [ ] 二十人团队：3分钟
- [ ] 固定时间（所有副本都一样）
- [ ] **您的选择：** _______________

#### B. 副本地图/场景
副本需要不同的场景吗？

**选项：**
- [ ] 不需要场景（只是一个战斗场地）
- [ ] 需要不同场景（如：洞窟、森林、神殿）
- [ ] 场景影响战斗（如：火焰场景，火属性伤害+10%）
- [ ] **您的选择：** _______________

#### C. 副本背景音乐/音效
副本需要不同的音乐吗？

**选项：**
- [ ] 不需要（所有副本使用相同音乐）
- [ ] 需要（不同副本不同音乐）
- [ ] 暂时不考虑（后续添加）
- [ ] **您的选择：** _______________

---

## 3. 类型（Type）

### 📝 这是什么意思？

**类型**就是副本属于哪种模式：
- 单人副本（一个人打）
- 五人小队副本（5个人组队）
- 二十人团队副本（20个人组队）

### 🎯 具体选项

#### A. 副本类型分类方式

**选项1：按游戏模式分类（推荐）**
- [ ] **单人野外副本**
  - 类型：单人
  - 用途：日常升级
  - 重置：每日

- [ ] **五人小队副本**
  - 类型：五人组队
  - 用途：获取专属武器材料
  - 重置：每周（周长）

- [ ] **二十人团队副本**
  - 类型：二十人组队
  - 用途：获取套装材料
  - 重置：每月（月度）

**选项2：按难度分类**
- [ ] 简单副本
- [ ] 普通副本
- [ ] 困难副本
- [ ] 噩梦副本

**选项3：按等级分类**
- [ ] 新手副本（1-10级）
- [ ] 初级副本（11-30级）
- [ ] 中级副本（31-60级）
- [ ] 高级副本（61-100级）

**您的选择：** _______________

#### B. 是否需要子类型？

**选项：**
- [ ] 不需要（只有三种主要类型：单人/五人/二十人）
- [ ] 需要（每种类型下还有细分）
  - 例如：单人副本下有"日常副本"和"特殊副本"
- [ ] **您的选择：** _______________

## 4. 解锁条件（Unlock Conditions）

### 📝 这是什么意思？

**解锁条件**就是玩家什么时候可以进入这个副本：
- 达到多少级
- 完成什么任务
- 拥有什么装备
- 或者其他条件

### 🎯 具体选项

#### A. 单人野外副本解锁条件

**选项：**
- [ ] **无条件**（创建角色就可以进入）
- [ ] **等级解锁**（达到X级可以进入）
  - 解锁等级：_______级（如：1级）
- [ ] **任务解锁**（完成X任务可以进入）
  - 任务名称：_______________
- [ ] **组合条件**（等级 + 任务）
  - 等级：_______级
  - 任务：_______________

**您的选择：** _______________

**示例：**
- 无条件：所有玩家都可以进入
- 等级1级：达到1级就可以进入
- 完成新手任务：完成"新手引导"任务后可以进入

#### B. 五人小队副本解锁条件

**选项：**
- [ ] **角色满级**（达到100级可以进入）
- [ ] **固定等级**（达到X级可以进入）
  - 解锁等级：_______级（如：50级）
- [ ] **完成前置副本**（完成X副本可以进入）
  - 前置副本：_______________
- [ ] **组合条件**（等级 + 完成副本）
  - 等级：_______级
  - 前置副本：_______________

**您的选择：** _______________

**示例：**
- 角色满级：达到100级（满级）可以进入
- 50级 + 完成单人副本：达到50级且完成"火焰洞窟"副本

#### C. 二十人团队副本解锁条件

**选项：**
- [ ] **拥有成型的五人小队**（完成过五人小队副本）
- [ ] **角色满级**（达到100级）
- [ ] **完成前置副本**（完成X个五人小队副本）
  - 需要完成数量：_______个
- [ ] **组合条件**（满级 + 完成五人副本）
  - 等级：_______级
  - 完成五人副本数量：_______个

**您的选择：** _______________

**示例：**
- 拥有成型的五人小队：至少完成过1次五人小队副本
- 满级 + 完成3个五人副本：达到100级且完成3个不同的五人小队副本

#### D. 是否需要副本等级限制？

**选项：**
- [ ] **需要**（副本有最低等级和最高等级要求）
  - 最低等级：_______级（低于此等级无法进入）
  - 最高等级：_______级（高于此等级无法进入，可选）
- [ ] **不需要**（任何等级都可以进入）
- [ ] **您的选择：** _______________

**示例：**
- 需要：副本1要求1-10级，副本2要求11-20级
- 不需要：所有玩家都可以进入，怪物等级根据玩家等级调整

## 📝 快速填写模板

如果您想快速开始，可以使用以下模板：

### 模板：简单明了（推荐）

```
1. 副本类：
   - 副本名称：使用简单名称（如：火焰洞窟）
   - 副本ID：使用数字ID（如：dungeon_001）
   - 副本描述：简单描述即可

2. 数据配置：
   - 副本时长：按游戏模式（单人1分钟，五人2分钟，二十人3分钟）
   - 副本场景：暂时不需要（后续添加）
   - 背景音乐：暂时不考虑

3. 类型：
   - 按游戏模式分类（单人/五人/二十人）
   - 不需要子类型

4. 解锁条件：
   - 单人副本：无条件（所有玩家都可以进入）
   - 五人副本：角色满级（100级）
   - 二十人副本：拥有成型的五人小队
   - 不需要等级限制
```

---

## 💡 通俗解释总结

1. **副本类** = 副本的基本信息（名字、ID、描述）
2. **数据配置** = 副本的具体内容（时长、场景、音乐）
3. **类型** = 副本属于哪种模式（单人/五人/二十人）
4. **解锁条件** = 什么时候可以进入副本（等级、任务等）
