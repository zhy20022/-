## 职业系统详细设计

### 职业分类

#### 物理系职业
1. **物理坦克**
   - 定位：前排肉盾，吸引仇恨
   - 特点：高HP、高物理防御
   - 基础属性：HP 2000, 物攻 80, 物防 200

2. **物理近战输出**
   - 定位：近战DPS
   - 特点：高物理攻击，中等生存能力
   - 基础属性：HP 1200, 物攻 180, 物防 100

3. **物理远程输出**
   - 定位：远程DPS
   - 特点：高物理攻击，低防御
   - 基础属性：HP 1000, 物攻 160, 物防 80

#### 法系职业
4. **法系坦克**
   - 定位：魔法防御型坦克
   - 特点：高HP、高魔法防御
   - 基础属性：HP 1800, 物攻 60, 物防 120, 魔攻 80, 魔防 220

5. **法系近战输出**
   - 定位：近战魔法DPS
   - 特点：高魔法攻击
   - 基础属性：HP 1100, 物攻 70, 物防 90, 魔攻 190, 魔防 100

6. **法系远程输出**
   - 定位：远程魔法DPS
   - 特点：高魔法攻击，低防御
   - 基础属性：HP 900, 物攻 50, 物防 70, 魔攻 170, 魔防 100

#### 支援系职业
7. **治疗**
   - 定位：恢复和支援
   - 特点：中等魔法攻击，治疗能力
   - 基础属性：HP 1000, 物攻 60, 物防 80, 魔攻 150, 魔防 120

8. **辅助**
   - 定位：增益和控场
   - 特点：提供buff和debuff
   - 基础属性：HP 1100, 物攻 70, 物防 90, 魔攻 130, 魔防 110

## 属性系统详细设计

### 属性相克关系图

```
风 → 火 → 木 → 风  (循环克制)
雷 → 水 → 土 → 雷  (循环克制)
光 ⇄ 暗  (相互克制)
```

### 伤害计算

- **克制关系**：造成150%伤害
- **被克制**：造成75%伤害
- **正常关系**：造成100%伤害
- **光暗互克**：相互造成150%伤害

### 属性应用

- 角色可以拥有一种主属性
- 技能可以带有属性效果
- 装备可以增加属性伤害

## 游戏模式详细设计

### 1. 单人野外模式

**解锁条件**：无（初始即可进入）

**重置周期**：每日重置

**奖励**：
- 经验值（用于升级）
- 基础材料（用于基础制作）

**玩法**：
- 玩家单独进行任务
- 可以自由选择难度
- 主要用于升级和熟悉游戏

### 2. 五人小队模式

**解锁条件**：角色满级（100级）

**重置周期**：每周重置（周长）

**团队配置建议**：
- 至少1个坦克
- 至少1个治疗
- 其余为输出职业

**奖励**：
- 专属武器抽取材料
- 副本内装备（固定，无法带出）

**玩法**：
- 可以单人匹配或组队进入
- 副本内装备临时使用
- 完成副本获得材料，用于抽取专属武器

### 3. 二十人团队模式

**解锁条件**：拥有成型的五人小队

**重置周期**：每月重置（月度）

**团队配置建议**：
- 至少2-3个坦克
- 至少2-3个治疗
- 其余为输出职业

**奖励**：
- 套装制作材料
- 副本内饰品（固定，无法带出）

**玩法**：
- 需要4个五人小队组成
- 副本内饰品临时使用
- 完成副本获得材料，用于制作套装

### 4. 全服击杀活动

**解锁条件**：拥有成型的二十人团队

**重置周期**：每季度重置（90天）

**奖励**：
- 立绘兑换材料
- 活动期间特殊加成（1.5倍）

**玩法**：
- 全服玩家共同参与
- 根据贡献度分配奖励
- 活动期间所有玩家获得加成

## 角色系统详细设计

### 角色属性

角色属性由以下部分组成：
1. **基础属性**：来自职业
2. **等级加成**：每级增加5%
3. **装备加成**：来自专属武器和套装

### 专属武器系统

- 每个角色拥有独特的专属武器
- 通过五人小队副本材料抽取
- 专属武器提供：
  - 属性加成
  - 特殊技能
  - 角色特定效果

### 套装系统

- 每个角色可穿戴6件套装
- 通过二十人团队副本材料制作
- 套装效果：
  - 2件套：基础加成
  - 4件套：中等加成
  - 6件套：完整加成

### 立绘系统

**设计理念**：
- 角色没有固定性别
- 玩家自行定义角色性别
- 每个角色提供男女两种立绘

**联机显示**：
- 玩家A选择男立绘，玩家B选择女立绘
- 联机时，玩家A看到的是男立绘，玩家B看到的是女立绘
- 每个玩家在自己的屏幕上看到自己选择的立绘

**获取方式**：
- 通过全服活动材料兑换
- 每个角色有多个立绘可选

## 版本/纪元系统详细设计

### 纪元概念

- **一年一个大版本**：每年更新一次
- **一个纪元 = 100年**：代表游戏世界的时间推进
- **纪元更替**：可以理解为朝代更替或科技进步

### 版本隔离机制

#### 角色版本绑定
- 每个版本的角色只能在当前版本使用
- 新版本发布时，旧版本角色被淘汰
- 旧版本角色无法参与新版本内容

#### 旧版本兼容
- 旧版本角色仍可参与旧版本副本
- 防止数值膨胀
- 防止新角色碾压旧版本
- 防止旧角色无法适应新版本

### 版本更新流程

1. **新版本发布**
   - 创建新的游戏版本
   - 引入新角色、新副本、新装备
   - 旧版本角色标记为"旧版本"

2. **玩家迁移**
   - 玩家可以继续使用旧版本角色打旧版本副本
   - 玩家需要创建新版本角色参与新版本内容
   - 旧版本角色数据保留

3. **内容平衡**
   - 新版本内容独立平衡
   - 旧版本内容保持原样
   - 避免跨版本数值问题

## 联机系统设计

### 立绘显示机制

**核心原理**：
- 每个玩家客户端独立存储立绘选择
- 服务器只传输角色ID和立绘ID
- 客户端根据本地选择显示对应立绘

**实现方式**：
1. 玩家选择立绘后，选择存储在本地
2. 联机时，服务器发送角色ID
3. 客户端根据角色ID和本地选择加载对应立绘
4. 不同玩家看到不同的立绘

### 团队匹配

**五人小队匹配**：
- 单人匹配：自动匹配其他玩家
- 组队匹配：玩家自行组队

**二十人团队匹配**：
- 需要4个完整的五人小队
- 可以跨服务器匹配
- 支持固定团队

### 数据同步

- 角色属性实时同步
- 装备效果实时计算
- 立绘选择本地存储
- 战斗数据服务器验证

## 游戏平衡性设计

### 职业平衡

- 每个职业有明确的定位
- 团队需要多种职业配合
- 避免单一职业过强

### 属性平衡

- 相克关系形成循环
- 光暗互克提供策略性
- 避免单一属性过强

### 版本平衡

- 每个版本独立平衡
- 避免跨版本数值问题
- 保持游戏长期可玩性
