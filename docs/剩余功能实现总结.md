## 🔧 实现详情

### 1. 怪物属性计算

```python
# 基础属性（根据副本类型）
1人本：HP 500, 攻击 50, 防御 25
5人本：HP 1000, 攻击 100, 防御 50
20人本：HP 2000, 攻击 200, 防御 100

# 时间倍率
time_multiplier = 1.0 + (current_time * 0.01)  # 每秒+1%

# 难度倍率
difficulty_multiplier = 1.0  # 暂时只有普通难度

# 最终属性
最终属性 = 基础属性 × 时间倍率 × 难度倍率
```

### 2. 怪物等级

```python
1人本：10级
5人本：20级
20人本：30级
```

### 3. 怪物职业和技能

- **小怪**：没有职业，只会普通攻击
- **Boss**：有职业（随机选择），有技能槽（后续可以添加特殊技能）

### 4. 群体小怪

- **3个小怪**：每个小怪HP = 总HP / 3
- **5个小怪**：每个小怪HP = 总HP / 5
- **总血量**：与单体小怪持平

### 5. Boss系统

- **Boss属性**：小怪的5倍
- **Boss职业**：随机选择（暂时）
- **Boss技能槽**：支持特殊技能（暂时为空，后续扩展）
- **Boss阶段**：支持阶段转换（暂时为空，后续扩展）

### 6. 全服Boss系统

- **伤害统计**：累计统计（每个玩家单独挑战）
- **最大伤害**：记录每个玩家的本周最高一次伤害
- **伤害排名**：显示前100名
- **每周结算**：固定时间结算，14次结算机会
- **奖励**：立绘拼图碎片，所有人相同奖励
- **Boss血量**：无限血量（只统计伤害）

## 🚀 使用示例

### 1. 生成怪物

```python
from src.enemies.enemy_factory import EnemyFactory
from src.enemies.enemy import EnemyType
from src.dungeons.dungeon_database import get_dungeon_by_id

# 获取副本
dungeon = get_dungeon_by_id("fire_type_single_001")

# 生成单体小怪
enemies = EnemyFactory.create_enemy(
    dungeon=dungeon,
    enemy_type=EnemyType.SINGLE,
    current_time=10.0,  # 10秒时生成
    enemy_index=0
)

# 生成群体小怪（3个）
group_enemies = EnemyFactory.create_enemy(
    dungeon=dungeon,
    enemy_type=EnemyType.GROUP_3,
    current_time=20.0,
    enemy_index=1
)
```

## 📝 注意事项

1. **属性克制**：怪物属性一定是被角色属性克制的
   - 火副本的怪物是木属性（火克木）

2. **时间倍率**：怪物随时间变强（每秒+1%）

   - 60秒时：属性 = 基础属性 × 1.6

3. **群体小怪**：总血量与单体小怪持平
   - 3个小怪：每个HP = 总HP / 3
   - 5个小怪：每个HP = 总HP / 5

4. **Boss属性**：Boss属性是小怪的5倍
