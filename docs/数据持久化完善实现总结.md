## 🔌 API接口

### 1. 获取玩家统计数据
```
GET /api/player/statistics?use_cache=true
```
**参数：**
- `use_cache` (可选): 是否使用缓存，默认 `true`

**返回：**
```json
{
  "success": true,
  "statistics": {
    "battles_completed": 10,
    "dungeons_completed": 5,
    "monsters_killed": 50,
    "character_count": 3,
    "total_gold_earned": 10000,
    "total_materials_dropped": 20,
    "total_materials_earned": 30,
    "level": 5
  }
}
```

### 2. 同步玩家统计数据
```
POST /api/player/statistics/sync
```
**说明：** 从数据库重新计算并更新统计数据

**返回：**
```json
{
  "success": true,
  "message": "统计数据已同步",
  "statistics": { ... }
}
```

## ⚠️ 注意事项

### 1. 材料统计说明
- **总掉落材料数量**：当前统计所有材料（因为MaterialModel中没有"dropped"标识）
- **总获得材料数量**：统计所有材料的总数
- **建议**：如果需要在MaterialModel中添加材料来源标识，可以后续优化

### 2. 统计数据一致性
- 统计表数据可能与实际数据有轻微差异（由于实时更新）
- 可以定期调用同步接口修复数据
- 或者使用实时计算模式获取准确数据

### 3. 性能考虑
- 使用缓存模式查询速度快，但可能不是最新数据
- 使用实时计算模式数据准确，但查询较慢
- 建议：日常查询使用缓存，重要操作使用实时计算
