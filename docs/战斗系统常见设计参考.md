# 战斗系统常见设计参考

本文档提供一些常见的战斗系统设计选项，帮助您做出决策。

---

## 1. 战斗类型参考

### 回合制（Turn-Based）
**特点：**
- 玩家和怪物轮流行动
- 有充足时间思考策略
- 适合策略性游戏

**代表游戏：**
- 最终幻想系列（早期）
- 仙剑奇侠传
- 火焰之纹章

**优点：**
- 策略性强
- 容易实现
- 适合新手

**缺点：**
- 节奏较慢
- 可能缺乏紧张感

---

### 即时制（Real-Time）
**特点：**
- 实时战斗
- 需要快速反应
- 类似动作游戏

**代表游戏：**
- 暗黑破坏神
- 原神
- 崩坏3

**优点：**
- 节奏快
- 紧张刺激
- 操作感强

**缺点：**
- 实现复杂
- 需要网络同步
- 对操作要求高

---

### 半即时制（ATB - Active Time Battle）
**特点：**
- 行动条系统
- 速度决定行动频率
- 结合回合制和即时制

**代表游戏：**
- 最终幻想7-9
- 轨迹系列

**优点：**
- 既有策略又有紧张感
- 速度属性很重要

**缺点：**
- 实现中等复杂度

---

## 2. 伤害计算公式参考

### 公式A：简单减法
```
伤害 = 攻击力 - 防御力
最终伤害 = max(伤害 × 属性倍率, 最小伤害)
```

**优点：**
- 简单易懂
- 计算快速

**缺点：**
- 防御力过高时可能无伤
- 平衡性较难控制

**适用场景：**
- 简单游戏
- 原型开发

---

### 公式B：百分比减伤
```
基础伤害 = 攻击力 × 技能倍率 × 属性倍率
减伤率 = 防御力 / (防御力 + 100)
最终伤害 = 基础伤害 × (1 - 减伤率)
```

**优点：**
- 永远不会无伤
- 平衡性好
- 防御力始终有效

**缺点：**
- 公式稍复杂

**适用场景：**
- 大多数RPG游戏
- 需要平衡性的游戏

---

### 公式C：混合公式
```
物理伤害 = (攻击力 × 技能倍率 - 防御力 × 0.5) × 属性倍率
魔法伤害 = (魔法攻击力 × 技能倍率) × (1 - 魔法防御 / (魔法防御 + 100)) × 属性倍率
最终伤害 = max(伤害, 攻击力的10%)
```

**优点：**
- 物理和魔法区分
- 平衡性好

**缺点：**
- 公式复杂

**适用场景：**
- 复杂的RPG游戏
- 需要区分物理和魔法

## 3. 状态系统参考

### 常见Buff类型
- **攻击力提升**：+20% 攻击力，持续3回合
- **防御力提升**：+30% 防御力，持续3回合
- **速度提升**：+50% 速度，持续2回合
- **暴击率提升**：+30% 暴击率，持续3回合
- **生命值回复**：每回合回复10%最大生命值，持续3回合

### 常见Debuff类型
- **攻击力降低**：-20% 攻击力，持续3回合
- **防御力降低**：-30% 防御力，持续3回合
- **速度降低**：-50% 速度，持续2回合
- **中毒**：每回合损失5%最大生命值，持续5回合
- **眩晕**：无法行动，持续1回合
- **燃烧**：每回合损失固定生命值，持续3回合
- **冰冻**：无法行动且防御力降低，持续2回合

## 4. AI系统参考

### 随机AI（最简单）
```python
def choose_action(enemy):
    available_skills = enemy.get_available_skills()
    return random.choice(available_skills)
```

**适用场景：**
- 简单敌人
- 原型开发

---

### 优先级AI（推荐）
```python
def choose_action(enemy):
    # 如果HP低于30%，优先使用治疗技能
    if enemy.hp / enemy.max_hp < 0.3:
        heal_skill = enemy.get_heal_skill()
        if heal_skill and heal_skill.can_use():
            return heal_skill
    
    # 如果玩家有Buff，使用驱散技能
    if player.has_buff():
        dispel_skill = enemy.get_dispel_skill()
        if dispel_skill and dispel_skill.can_use():
            return dispel_skill
    
    # 否则使用攻击技能
    return enemy.get_attack_skill()
```

**适用场景：**
- 大多数游戏
- Boss战

---

### 状态机AI（复杂）
```python
class EnemyAI:
    def __init__(self):
        self.state = "aggressive"  # aggressive, defensive, healing
    
    def choose_action(self, enemy):
        if self.state == "aggressive":
            return self.attack_state(enemy)
        elif self.state == "defensive":
            return self.defensive_state(enemy)
        elif self.state == "healing":
            return self.healing_state(enemy)
    
    def attack_state(self, enemy):
        # 攻击逻辑
        if enemy.hp / enemy.max_hp < 0.3:
            self.state = "defensive"
        return enemy.get_attack_skill()
```

**适用场景：**
- 复杂的Boss战
- 需要多种行为的敌人

## 5. 仇恨值系统参考

### 仇恨值计算
```python
# 造成伤害时增加仇恨
threat += damage * 1.0

# 治疗时增加仇恨（对治疗者）
threat += heal * 0.5

# 使用嘲讽技能时大幅增加仇恨
threat += 1000

# 每个回合衰减
threat *= 0.95
```

### 目标选择
```python
def choose_target(enemy, players):
    # 选择仇恨值最高的玩家
    return max(players, key=lambda p: p.threat[enemy.id])
```

## 6. 战斗流程参考

### 回合制战斗流程
```
1. 战斗开始
   - 初始化战斗状态
   - 计算初始行动顺序
   - 显示战斗UI

2. 战斗循环
   while not battle.is_finished():
       # 获取当前行动者
       actor = battle.get_current_actor()
       
       # 选择行动
       action = actor.choose_action()
       
       # 执行行动
       battle.execute_action(action)
       
       # 更新状态（Buff/Debuff回合数-1）
       battle.update_statuses()
       
       # 检查战斗结束
       if battle.check_victory():
           break
       if battle.check_defeat():
           break
       
       # 移动到下一个行动者
       battle.next_actor()

3. 战斗结束
   - 显示结算界面
   - 发放奖励
   - 保存数据
```
