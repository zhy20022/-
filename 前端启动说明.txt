========================================
  前端服务器启动说明
========================================

【当前状态】
✅ 后端服务器已启动（端口 5000）
❓ 前端服务器可能未启动（端口 3000）

【解决方法】

方法1：手动启动前端服务器（推荐）
----------------------------------------
1. 双击运行：启动前端.bat
2. 等待看到类似以下信息：
   VITE v5.x.x  ready in xxx ms
   ➜  Local:   http://localhost:3000/
3. 在浏览器中访问：http://localhost:3000

方法2：检查是否有前端服务器窗口
----------------------------------------
1. 查看是否有标题为 "Frontend Server" 的窗口
2. 如果有，查看窗口中的错误信息
3. 如果没有，说明前端未启动，使用方法1启动

方法3：在命令行中手动启动
----------------------------------------
1. 打开命令行窗口
2. 进入游戏目录：cd C:\Users\12107\Desktop\4\Gamer
3. 进入 web 目录：cd web
4. 启动前端：npm run dev
5. 等待看到服务器启动信息后，访问 http://localhost:3000

【验证服务器状态】
----------------------------------------
打开命令行，运行以下命令检查：

检查后端（应该看到端口 5000）：
  netstat -ano | findstr ":5000"

检查前端（应该看到端口 3000）：
  netstat -ano | findstr ":3000"

【访问游戏】
----------------------------------------
当两个服务器都启动后：
- 在浏览器中访问：http://localhost:3000
- 如果浏览器没有自动打开，手动输入上述地址

【注意事项】
----------------------------------------
1. 后端和前端需要在两个不同的窗口中运行
2. 不要关闭这两个服务器窗口
3. 关闭游戏时，需要分别关闭后端和前端服务器窗口
