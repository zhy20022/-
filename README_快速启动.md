# 🎮 游戏快速启动

## 方式一：双击启动（最简单）✨

### Windows 用户
**直接双击 `启动游戏.bat` 文件即可！**

启动器会自动：
- ✅ 检查 Python 和 Node.js 环境
- ✅ 安装前端依赖（首次运行）
- ✅ 启动后端服务器
- ✅ 启动前端服务器
- ✅ 自动打开浏览器

---

## 方式二：Python 启动器

**双击 `启动游戏.py` 文件**

或者命令行运行：
```bash
python 启动游戏.py
```

---

## 方式三：手动启动（高级用户）

如果需要手动控制，参考 `docs/游戏启动指南.md`

---

## ⚠️ 首次运行前

### 必须安装的软件：

1. **Python 3.8+**
   - 下载：https://www.python.org/downloads/
   - 安装时勾选"添加到 PATH"

2. **Node.js 16+**
   - 下载：https://nodejs.org/
   - 选择 LTS 版本，安装时勾选"添加到 PATH"

3. **PostgreSQL 12+**（可选，但推荐）
   - 下载：https://www.postgresql.org/download/windows/
   - 安装后创建数据库 `gamedb`
   - 启动 PostgreSQL 服务

---

## 🚀 启动后

游戏会自动在浏览器中打开：**http://localhost:5173/**

如果浏览器没有自动打开，请手动访问上述地址。

---

## ❓ 常见问题

### 启动失败？
1. 确认已安装 Python 和 Node.js
2. 确认 PostgreSQL 已启动（如果使用数据库）
3. 查看启动器窗口的错误信息

### 端口被占用？
- 后端端口 5000 被占用：关闭占用该端口的程序
- 前端端口 5173 被占用：Vite 会自动使用下一个可用端口

### 数据库连接失败？
- 确认 PostgreSQL 服务已启动
- 确认数据库 `gamedb` 已创建
- 首次运行会自动创建数据表
