========================================
  灾异志 - 游戏启动说明
========================================

【快速启动】
----------------------------------------
直接双击运行: 启动游戏.bat

脚本会自动：
1. 检查 Python 和 Node.js 环境
2. 检查必要文件
3. 启动后端服务器（新窗口）
4. 启动前端服务器（新窗口）
5. 10秒后自动打开浏览器

【手动启动（如果自动启动失败）】
----------------------------------------

方法1：分别启动
1. 打开命令行，进入游戏目录
2. 启动后端：python run_server.py
3. 打开新命令行窗口
4. 启动前端：cd web && npm run dev
5. 浏览器访问：http://localhost:3000

方法2：使用单独脚本
1. 后端已在运行时，双击：启动前端.bat

【环境检查】
----------------------------------------
双击运行: 检查环境.bat

检查项目：
- Python 是否安装
- Node.js 是否安装
- 必要文件是否存在
- 端口是否被占用

【访问游戏】
----------------------------------------
后端服务器: http://localhost:5000
前端游戏: http://localhost:3000

【注意事项】
----------------------------------------
1. 后端和前端需要在两个窗口中运行
2. 不要关闭服务器窗口
3. 关闭游戏时，请关闭后端和前端服务器窗口
4. 首次运行会自动安装前端依赖，需要一些时间

【常见问题】
----------------------------------------

问题：提示 Python 未安装
解决：安装 Python 3.8+，下载地址: https://www.python.org/downloads/
     安装时勾选"添加到 PATH"

问题：提示 Node.js 未安装
解决：安装 Node.js，下载地址: https://nodejs.org/
     安装时勾选"添加到 PATH"

问题：前端依赖安装失败
解决：检查网络连接，或使用国内镜像:
     npm config set registry https://registry.npmmirror.com

问题：端口被占用
解决：关闭占用端口的程序，或重启电脑
