========================================
  灾异志 - 启动问题解决指南
========================================

如果双击"启动游戏.bat"无法启动游戏，请按以下步骤排查：

【第一步】运行诊断工具
----------------------------------------
1. 双击运行"启动游戏诊断.bat"
2. 查看诊断结果，找出具体问题

【第二步】常见问题及解决方案
----------------------------------------

问题1：提示"未找到 Python"
解决：
  - 确认已安装 Python 3.8 或更高版本
  - 安装时勾选"添加到 PATH"
  - 或手动将 Python 安装目录添加到系统 PATH
  - 下载地址：https://www.python.org/downloads/

问题2：提示"未找到 Node.js"
解决：
  - 确认已安装 Node.js 16 或更高版本
  - 安装时勾选"添加到 PATH"
  - 下载地址：https://nodejs.org/
  - 安装后需要重新打开命令行窗口

问题3：提示"找不到 run_server.py 文件"
解决：
  - 确认在游戏根目录运行启动脚本
  - 不要从其他位置运行，或使用快捷方式
  - 右键点击"启动游戏.bat"，选择"以管理员身份运行"

问题4：提示"前端依赖安装失败"
解决：
  - 检查网络连接
  - 尝试手动运行：cd web && npm install
  - 如果网络慢，可以使用国内镜像：
    npm config set registry https://registry.npmmirror.com

问题5：启动后窗口立即关闭
解决：
  - 可能是编码问题，尝试使用"启动游戏.py"（Python版本）
  - 或在命令行中运行：启动游戏.bat
  - 查看是否有错误信息

问题6：端口被占用
解决：
  - 关闭其他占用 5000 或 3000 端口的程序
  - 或关闭之前未正常退出的游戏服务器窗口
  - 检查是否有其他 Python 或 Node.js 进程在运行

【第三步】替代启动方法
----------------------------------------

方法1：使用 Python 启动器
  - 双击"启动游戏.py"
  - 或命令行运行：python 启动游戏.py

方法2：手动启动（分步操作）
  步骤1：打开命令行，进入游戏目录
  步骤2：运行：python run_server.py
  步骤3：打开新的命令行窗口
  步骤4：运行：cd web && npm run dev
  步骤5：等待看到服务器启动信息后，浏览器访问：
         http://localhost:3000

【第四步】获取详细错误信息
----------------------------------------
1. 右键点击"启动游戏.bat"
2. 选择"编辑"（用记事本打开）
3. 找到包含 "pause" 的行，确保脚本在出错时会暂停
4. 在命令行中运行脚本，查看完整错误信息

【第五步】如果仍然无法解决
----------------------------------------
1. 运行"诊断启动问题.bat"获取详细诊断信息
2. 运行"测试启动环境.bat"检查基本环境
3. 运行"快速诊断游戏问题.bat"检查服务器状态
4. 查看启动窗口中的具体错误信息
5. 检查是否有防病毒软件阻止了脚本运行
