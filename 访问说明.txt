===============================
  游戏访问说明
===============================

您看到 {"message":"未登录","success":false} 说明：
✅ 后端服务器正常运行（端口 5000）

但是前端服务器还没有启动，需要启动前端才能看到游戏界面。

===============================
  如何启动前端
===============================

方法1：双击运行
  → 双击 "启动前端.bat" 文件

方法2：命令行启动
  1. 打开 PowerShell 或 CMD
  2. 进入项目目录
  3. 运行：
     cd web
     npm run dev

===============================
  访问地址
===============================

启动前端后，在浏览器中访问：
  → http://localhost:3000

这是游戏的主页面，您会看到登录界面。

===============================
  如果端口3000被占用
===============================

Vite 会自动使用下一个可用端口（3001, 3002等）
请查看启动时的输出信息，会显示实际使用的端口。

===============================
  常见问题
===============================

Q: 只看到 JSON 数据？
A: 您访问了后端 API 地址，应该访问前端页面 http://localhost:3000

Q: 无法访问？
A: 确认前端服务器已启动（命令行窗口正在运行）

Q: 端口被占用？
A: 查看启动输出，使用显示的端口号访问
