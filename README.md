## 游戏概述

一款以游戏世界人类与异度空间怪物对战为主题的多人在线角色扮演游戏（MMORPG）。

## 核心系统

### 1. 职业系统（8种职业）

- **物理坦克**：高防御、高生命值，负责吸引怪物仇恨
- **物理近战输出**：近距离物理伤害输出
- **物理远程输出**：远距离物理伤害输出
- **法系坦克**：魔法防御型坦克，使用魔法护盾
- **法系近战输出**：近距离魔法伤害输出
- **法系远程输出**：远距离魔法伤害输出
- **治疗**：恢复队友生命值和状态
- **辅助**：提供增益效果和团队支援

### 2. 属性系统（8种属性）

#### 属性相克关系
- **风** 克 **火**
- **火** 克 **木**
- **木** 克 **风**
- **雷** 克 **水**
- **水** 克 **土**
- **土** 克 **雷**
- **光** 与 **暗** 相互克制

#### 属性效果
- 对克制属性造成额外伤害
- 被克制属性造成伤害减少
- 光暗相互克制，伤害相互增强

### 3. 游戏模式

#### 3.1 单人野外模式
- **类型**：日常任务
- **目的**：升级、获取基础资源
- **解锁条件**：无
- **奖励**：经验值、基础材料

#### 3.2 五人小队模式
- **类型**：周长副本（每周刷新）
- **目的**：获取专属武器抽取材料
- **解锁条件**：角色满级
- **奖励**：
  - 专属武器抽取材料
  - 副本内装备（固定，无法带出副本）
- **组队方式**：单人匹配或联机组队

#### 3.3 二十人团队模式
- **类型**：月度副本（每月刷新）
- **目的**：获取套装制作材料
- **解锁条件**：拥有成型的五人小队
- **奖励**：
  - 套装制作材料
  - 副本内饰品（固定，无法带出副本）
- **组队方式**：联机组队（4个五人小队组成）

#### 3.4 全服击杀活动
- **类型**：季度活动（每季度一次）
- **目的**：获取立绘兑换材料
- **解锁条件**：拥有成型的20人团队
- **奖励**：
  - 立绘兑换材料
  - 活动期间特殊加成
- **参与方式**：全服玩家共同参与

### 4. 角色系统

#### 4.1 专属武器
- 每个角色拥有独特的专属武器
- 通过五人小队副本获得的材料抽取
- 专属武器具有角色特定的技能和属性加成

#### 4.2 套装系统
- 每个角色可穿戴套装
- 套装通过20人团队副本获得的材料制作
- 套装提供强大的属性加成和套装效果

#### 4.3 立绘系统
- 角色没有固定性别，由玩家自行定义
- 每个角色提供男女两种立绘选项
- 玩家选择立绘后，在自己的游戏界面显示所选立绘
- 联机时，每个玩家看到的是自己选择的立绘版本
- 立绘通过全服活动材料兑换

### 5. 版本/纪元系统

#### 5.1 纪元概念
- 一年一个大版本更新
- 每个大版本代表一个游戏纪元（100年）
- 可以理解为朝代更替或科技进步的时间递推

#### 5.2 版本隔离机制
- **角色版本绑定**：每个版本的角色只能在当前版本使用
- **大版本更新**：新版本发布时，旧版本角色被淘汰
- **旧版本兼容**：
  - 旧版本角色仍可参与旧版本副本
  - 防止数值膨胀
  - 防止新角色碾压旧版本内容
  - 防止旧角色无法适应新版本

#### 5.3 版本更新策略
- 每个纪元引入新的角色、副本、装备
- 保持游戏内容的持续更新
- 维护游戏平衡性

## 游戏流程

1. **新手阶段**：创建角色 → 选择职业 → 单人野外升级
2. **满级阶段**：参与五人小队周长副本 → 获取专属武器
3. **进阶阶段**：组建20人团队 → 参与月度副本 → 制作套装
4. **高级阶段**：参与全服季度活动 → 兑换立绘
5. **版本更新**：新纪元开启 → 创建新版本角色 → 重复流程

### 项目结构
```
Gamer/
├── README.md                 # 游戏设计文档
├── docs/                     # 详细设计文档
├── src/                      # 源代码
│   ├── classes/             # 职业系统
│   ├── attributes/          # 属性系统
│   ├── game_modes/          # 游戏模式
│   ├── characters/          # 角色系统
│   ├── versions/            # 版本系统
│   └── utils/               # 工具类
├── data/                     # 游戏数据
└── tests/                    # 测试代码
```
